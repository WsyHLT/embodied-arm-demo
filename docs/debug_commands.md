# 机械臂调试指令集

场景物体：`red_cube` 红色方块 / `blue_cube` 蓝色方块 / `green_cylinder` 绿色圆柱

---

## 一、基础抓放（验证单步 pick & place）

1. 把红色的放到蓝色的旁边
2. 把蓝色方块放到绿色圆柱旁边
3. 把绿色圆柱放到红色方块旁边
4. 把红色的拿过来
5. 拿起蓝色方块
6. 抓取那个绿色圆柱
7. 把红色的移开
8. 移动蓝色方块到桌子右边
9. 把绿色圆柱挪一下
10. 把红色方块放到绿色圆柱的左边

## 二、叠放（验证 on_top 高度计算 + 多物体交互）

11. 把红色的放到蓝色的上面
12. 把蓝色方块叠到绿色圆柱上面
13. 把绿色圆柱放在红色方块上面
14. 把三个物体都叠在一起
15. 把红色的叠起来
16. 把蓝色方块放到红色方块正上方
17. 堆一个红色方块在蓝色方块上面

## 三、交换 / 重排（验证大脑多步规划 + 挪开腾位）

18. 交换红色方块和蓝色方块的位置
19. 把蓝色方块和红色方块换个位置
20. 把红色方块和绿色圆柱调换一下
21. 让蓝色方块在红色方块上面（如果已叠）
22. 把压在红色上面的东西挪开
23. 重新排列这三个物体，红色在最左边
24. 把蓝色方块放到红色方块旁边，同时把绿色圆柱放到蓝色旁边
25. 把这堆东西整理一下，红的在中间

## 四、复杂 / 连续操作（验证多步执行 + 状态跟踪）

26. 先把蓝色方块放到红色上面，再把绿色圆柱放到蓝色上面
27. 把红色方块放到绿色圆柱旁边，然后把蓝色方块放到红色旁边
28. 先抓起蓝色方块，放到桌子上，再抓起红色方块放到蓝色上面
29. 把绿色圆柱搬到蓝色方块上面，然后把它们一起放到红色旁边
30. 把红色和蓝色叠起来，放到绿色圆柱旁边

## 五、模糊 / 歧义（验证大脑如何处理不确定）

31. 把那个方块拿过来
32. 把它放到旁边
33. 整理一下桌子
34. 把红色的放到上面
35. 随便放一个到旁边
36. 拿个东西过来

## 六、异常 / 边界（验证容错，不会崩溃）

37. 把黑色的箱子拿起来（不存在的物体）
38. 把绿色圆柱放到桌子外面（不可达位置）
39. 放到天上去
40. 把所有东西都扔掉
41. 把红色方块放到蓝色方块下面（桌子下面，物理不可行）
42. 把红色方块放到它自己上面（自叠放）
43. 红色方块红色方块（无意义）
44. 你好（打招呼，无任务）
45. 今天天气怎么样（无关问题）
46. 转个圈（机械臂无此能力）
47. 什么都不做
48. （空指令）

## 七、同义词 / 别名（验证别名映射覆盖）

49. 把红的放到蓝的旁边
50. 拿起红块放到绿柱子旁边
51. 把红色立方体放到蓝色方块上面
52. 拿那个红的
53. 把绿圆柱放到红方块上面
54. 移动 red cube 到 blue cube 旁边（英文名）
55. 把蓝色放绿色上（省略"方块/圆柱"）

## 八、压力测试（连续多次，验证状态累积）

56. 把红色放到蓝色上面（第1次）
57. 把红色放到蓝色旁边（第2次，红色应该已移动）
58. 把蓝色放到绿色上面（第3次）
59. 交换红色和蓝色（第4次，此时已是叠放状态）
60. 把所有东西放回原位（第5次）
